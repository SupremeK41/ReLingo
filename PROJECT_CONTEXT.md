# Project context

ReLingo is my solo academic Master's dissertation project at the University of Birmingham. It combines a React interface, a Python/FastAPI backend, SQLite and AI services for speech-therapy exercises.

It is an academic prototype, not a clinically validated product. The existing project documentation and source are retained; this organisation update does not claim new clinical validation, test results, deployments or user outcomes.
